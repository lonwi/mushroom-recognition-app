Attributions and licences

Where the photos in the app come from, how they are credited, and what licence the code is under. As of 22 October 2026.

Photos

Mushroom photos in the app are under CC0 or CC BY. Training accepts only those two licence families, at any version of them. It rejects NC, ND, SA, all-rights-reserved, and a photo with no licence of its own.

Each photo keeps its author, licence, and source address. CC BY credit has to stay with the photo.

In the app the list is in Settings, under “Dataset photo credits”. It shows the author, the licence, the species, and the source page. Atlas-card photos stay on that list even when no model is installed. When a model is installed, the list also includes training photos, test photos, and evaluation probes. How those credits are stored is described in training/ATTRIBUTION.md.

This website does not show mushroom photos. The frames on the home page are placeholders. The header icon is the app’s own drawing (assets/icon.svg in the repository), not an atlas photograph.

Maps

The app has no maps yet. That feature is planned. When it exists, map data will be credited as © OpenStreetMap contributors.

Code

The repository has no LICENSE file. The application code is not released under an open-source licence by that file. Rights stay with the repository owner until such a file is added.

The MobileNetV3-Small starting weights, used only for training, are described in training/README.md (Apache-2.0 for the Keras code). That is not the licence of the application code.

Do not eat a mushroom based only on this app. Poisoning: 112 or 999. Toxicology-centre numbers are in the app’s Help section (Pomoc).
