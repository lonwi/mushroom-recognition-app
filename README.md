# Grzybobranie AI

Aplikacja offline do oznaczania grzybów. Ta gałąź to Faza 0: szkielet na Expo SDK 58, trzy zakładki (Atlas, Skaner, Pomoc) i kontrakt manifestu modelu. Rozpoznawanie jeszcze nie działa, bo nie ma modelu w pakiecie. Model nie ocenia jadalności.

Instrukcja dla agentów: [AGENTS.md](AGENTS.md).

```bash
pnpm install --frozen-lockfile
pnpm start
pnpm quality
```

Pomiar motywów na telefonie: Ustawienia → Spike stylowania. Kroki są w [docs/spikes/F0-raport.md](docs/spikes/F0-raport.md).
